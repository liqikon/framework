## 교안 미리보기 (Office Viewer 플러그인)

교안은 마크다운(`.md`)으로 제공됩니다. **Antigravity(VS Code 계열) IDE에서 교안을
보기 좋게 렌더링**하려면 아래 플러그인 설치를 권장합니다.

1. IDE 좌측 **Extensions(확장)** 패널 열기 (`Cmd+Shift+X` / `Ctrl+Shift+X`)
2. 검색창에 **`Office Viewer`** 입력 후 설치
3. 교안 `.md` 파일을 열고 우측 상단 **미리보기(Preview)** 아이콘 클릭
   - 또는 `.md` 파일에서 우클릭 → **Open Preview**

> Office Viewer를 사용하면 표·이미지·서식이 포함된 교안을 편집 화면이 아닌
> 깔끔한 문서 형태로 읽을 수 있습니다. PDF 버전(`W1교안_..._v3_*.pdf`)도 함께
> 제공되니 인쇄/오프라인 열람에 활용하세요.

## 새 교안 받는 법

매주 새 교안이 공개되면 강사가 Slack에 안내합니다. 본인 로컬에서:

```bash
cd ~/AP-Lecture-01

```

해당 주차 교안 파일이 `01.강의교재/` 폴더에 자동 등장합니다.

## 왜 순차 공개인가요?

각 주차는 **이전 주차의 산출물**을 입력으로 사용하는 Document Chaining 흐름입니다.
미리 다음 주 교안을 보면 강의 흐름의 "마법" 모먼트(예: P-101로 17개 폴더 한 번에 생성)가
김빠질 수 있어, 강사 시연과 동시에 학습 경험을 극대화하기 위함입니다.

물론 W1을 충실히 완료하시면 W2부터는 **본인 프로젝트 진도가 강의 진도와 동기화**되므로
"미리 봐야 할" 필요가 없게 설계되어 있습니다.
