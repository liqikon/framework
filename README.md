## 표준 환경

- **IDE**: Antigravity + Claude Code 플러그인
- **프레임워크**: AP-Framework V0.43
- **기술 스택**: Next.js + Tailwind CSS / Express.js / PostgreSQL / Vercel
- **자동화**: n8n Cloud
- **AI 위키**: NotebookLM (P-104 양방향 동기화)
